# Схема веток

Простая модель без долгоживущих интеграционных веток. См. [README.md](README.md) и [DEV-PROCESS.md](DEV-PROCESS.md).

| Ветка           | Назначение                                                                                   |
| --------------- | -------------------------------------------------------------------------------------------- |
| **`main`**      | Стабильная линия: всё, что уже можно выкатывать или считать «истиной» в репозитории.         |
| **`feature/…`** | Новая функциональность. Ответвляйтесь от актуального `main`, после готовности — PR в `main`. |
| **`fix/…`**     | Исправления багов. То же: от `main`, merge через PR.                                         |

**Правило:** в `main` не коммитим напрямую с рабочей машины — только merge/rebase из PR (желательно включить branch protection, см. [DEV-PROCESS.md](DEV-PROCESS.md)).

**Релизы:** теги `v*` и GitHub Release с `main` после обновления версии и `CHANGELOG.md` (см. [CONTRIBUTING.md](../CONTRIBUTING.md)).
