## Smoke-тест на проде (~20 мин)

Проверить **свежим** Telegram-аккаунтом (без Premium) и **админским**.

### Базовый уровень (без промо)

- `/start` — при первом заходе после деплоя **3.7+**: блок «Что нового» + «Понятно»; затем список раскладов (🌱/⭐️, названия в «»)
- Кнопки: 🌱 «На день», 🌱 «Прошлое — настоящее — будущее», 🌱 «Глубинная диагностика», ⭐️ «Промокод (Premium)»
- «На день» — фото + текст; повтор в тот же день — лимит
- Spread — «Начать» / «Отмена», вопрос, карты; на basic — до **3** раскладов за календарные сутки
- Deep — до 3 вопросов, **без** общего финала; копирайт про Premium понятен
- `/help` — уровень доступа, расклады, лимиты, рассылка (то же, что `/status`)

### Premium (промокод)

- `/admin promo` — код вида `STAR-LANTERN-XXXXXX`; участнику — **plain** `/promo КОД`
- `/promo КОД` или пересылка plain-сообщения — Premium на ~31 день; меню обновилось
- ⭐️ «Прошлое — настоящее — будущее» — без лимита по суткам; тот же flow «Начать» + вопрос
- Deep — до 7 вопросов + общий финал
- `/admin promo list` — код «активирован», указан user id

### Устойчивость

- Неверный `/promo` — нейтральный ответ (без «код существует»)
- 10+ неверных `/promo` подряд — rate limit (~15 мин)
- Перезапуск контейнера во время deep — сессия обрывается (ожидаемо)
- «Понятно» в «Что нового» — повтор блока не показывается до следующего релиза

## Выдача кодов участникам

1. На каждого участника: `/admin promo` (или пакетом заранее, список в таблице).
2. Сообщение участнику: **перешли** второе plain-сообщение бота после `/admin promo` (строка `/promo КОД` без форматирования). Либо вручную:

```
Открой бота в личке.
Скопируй строку от администратора целиком и отправь (начинается с /promo).
Или вставь только код одной строкой.
Затем /menu — все расклады на месте.
Вопросы: /help
```

**Не** копируй код из сообщения с жирным шрифтом/monospace — только из plain-сообщения или вводи `/promo КОД` вручную.

3. Учёт: `/admin promo list`; при сбое — `/admin grant TELEGRAM_ID 31`.

## Бриф для участников (коротко)

- Бот **открыт** для всех; Premium по **одноразовому** коду на ~**31 день** (фокус-группа, без оплаты в боте).
- На **базовом уровне** доступны «На день», расклад «три карты» (3 раза в сутки) и deep до 3 вопросов.
- Толкование — повод поразмыслить, **не** гарантия событий; не медицина и не юриспруденция.
- Незавершённое гадание может сброситься при **обновлении** сервера — лучше закончить сессию кнопкой «Закончить гадание».

## Обратная связь

Завести канал вне бота (форма, чат, таблица): баги, непонятные тексты, качество ИИ, длина ответов, удобство кнопок.

**Уже на радаре (бета):** слишком сложные толкования ИИ; активация промо — пересыл plain-сообщения `/promo …` от админа.

Полезные данные от админа: `/admin stats`, `/admin info USER_ID`, логи `docker compose logs bot` (см. [DEPLOY § логи](./DEPLOY.md#логи-и-runbook-оператор)).
