## Smoke-тест на проде (~15 мин)

Проверить **свежим** Telegram-аккаунтом (без Premium) и **админским**.

### Базовый трек (без промо)

- [ ] `/start` — кнопки: 🌱 «На день», 🌱 «Глубинная диагностика», ⭐️ «Промокод»; нет spread
- [ ] «На день» — фото + текст; повтор в тот же день — лимит
- [ ] Deep — до 3 вопросов, **без** общего финала; копирайт про Premium понятен
- [ ] `/status` — без слова «новичок»; есть 🌱 и ⭐️ у фич

### Premium (промокод)

- [ ] `/admin promo` — код вида `STAR-LANTERN-XXXXXX`
- [ ] `/promo КОД` — подтверждение Premium на месяц; меню обновилось
- [ ] ⭐️ «Прошлое — настоящее — будущее» — расклад с фото и текстом
- [ ] Deep — до 7 вопросов + общий финал
- [ ] `/admin promo list` — код «активирован», указан user id

### Устойчивость

- [ ] Неверный `/promo` — нейтральный ответ (без «код существует»)
- [ ] 10+ неверных `/promo` подряд — rate limit (~15 мин)
- [ ] Перезапуск контейнера во время deep — сессия обрывается (ожидаемо)

## Выдача кодов участникам

1. На каждого участника: **`/admin promo`** (или пакетом заранее, список в таблице).
2. Сообщение участнику (можно копировать):

   ```
   Открой бота в личке → введи:
   /promo ТВОЙ-КОД
   Затем /menu — появятся все расклады.
   Вопросы: /help  Статус Premium: /status
   ```

3. Учёт: **`/admin promo list`**; при сбое — **`/admin grant TELEGRAM_ID 31`**.

## Бриф для участников (коротко)

- Бот **открыт** для всех; Premium по **одноразовому** коду на ~**31 день** (фокус-группа, без оплаты в боте).
- Толкование — повод поразмыслить, **не** гарантия событий; не медицина и не юриспруденция.
- Незавершённое гадание может сброситься при **обновлении** сервера — лучше закончить сессию кнопкой «Закончить гадание».

## Обратная связь

Завести канал вне бота (форма, чат, таблица): баги, непонятные тексты, качество ИИ, длина ответов, удобство кнопок.

Полезные данные от админа: `/admin stats`, `/admin info USER_ID`, логи `docker compose logs bot` (см. [DEPLOY § логи](./DEPLOY.md#логи-и-runbook-оператор)).
