# Глоссарий терминов

Это словарь понятий бота **Водоворот** (_Vodovorot_) в духе **ubiquitous language**: одни и те же слова в коде, в Telegram и в документации, чтобы не путаться.

**Как читать.** Жирным выделены названия статей. Отсылка _см._ ведёт к связанной статье. В колонке «Где в коде» — файл или символ для начала поиска (с **2.14** пользовательская логика в `src/handlers/`, `src/bot.ts` — запуск). Имена env и API — моноширинным. Раздел 2 — терминология Таро; разделы 1 и 3–9 — Водоворот. Тон и формат толкования — [BRAND-GUIDE.md](BRAND-GUIDE.md). Указатель доков — [README.md](README.md).

## 2. Общепринятые термины Таро

Ниже — язык, который чаще всего встречается в книгах, курсах и обсуждениях колоды **78 карт**. Формулировки не привязаны к одной школе; там, где важно, отмечена связь с проектом.

| Термин                                            | Обычно значит                                                                                                      | В этом проекте                                                                                                                                                                                                                             |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Таро**                                          | Набор из 78 карт и практика работы с ними (расклады, вопросы, толкование).                                         | Бот оперирует полной колодой и текстовым разбором без «магических» заявлений в коде.                                                                                                                                                       |
| **Полная колода**                                 | Стандартно 22 старших + 56 младших аркана.                                                                         | Совпадает с `DECK`.                                                                                                                                                                                                                        |
| **Аркан**                                         | «Тайна»; в бытовой речи — одна карта таро (и старшая, и младшая).                                                  | Синоним **карты** в пользовательском смысле.                                                                                                                                                                                               |
| **Старшие арканы (Major Arcana)**                 | 22 карты с номерами 0–XXI (от Шута до Мира); часто связывают с крупными жизненными темами и архетипами пути.       | `id` 0–21; русские имена в `MAJOR_ARCANA`.                                                                                                                                                                                                 |
| **Младшие арканы (Minor Arcana)**                 | 56 карт: четыре масти × 14 карт; «повседневный» слой ситуаций, настроений, деталей.                                | Четыре масти: Жезлы, Кубки, Мечи, Пентакли (аналог _Wands, Cups, Swords, Pentacles_).                                                                                                                                                      |
| **Масть (suit)**                                  | Одна из четырёх групп младших арканов с общей символикой.                                                          | В названии карты масть стоит в родительном падеже («… Жезлов»).                                                                                                                                                                            |
| **Жезлы (Wands)**                                 | Огонь, импульс, творчество, воля — в распространённых соответствиях мастей.                                        | Одна из четырёх мастей в коде.                                                                                                                                                                                                             |
| **Кубки (Cups)**                                  | Вода, чувства, отношения, интуиция.                                                                                | Одна из четырёх мастей.                                                                                                                                                                                                                    |
| **Мечи (Swords)**                                 | Воздух, мысль, конфликт, речь, решения.                                                                            | Одна из четырёх мастей.                                                                                                                                                                                                                    |
| **Пентакли (Pentacles)**                          | Земля, материя, тело, работа, ресурсы; встречаются имена _Coins, Disks_.                                           | В проекте — «Пентаклей» в родительном падеже.                                                                                                                                                                                              |
| **Туз (Ace)**                                     | Первая карта масти; начало, потенциал, «семя» темы.                                                                | Русское «Туз» + масть.                                                                                                                                                                                                                     |
| **Числовые карты**                                | В младших арканах — от двойки до десятки; развитие ситуации внутри масти.                                          | «Двойка» … «Десятка» в именах.                                                                                                                                                                                                             |
| **Придворные карты (court cards)**                | Паж, рыцарь, королева, король в каждой масти; часто читают как людей, роли или уровни зрелости.                    | Те же четыре ранга в `MINOR_RANKS`.                                                                                                                                                                                                        |
| **Колода Райдера–Уэйта (Rider–Waite–Smith, RWS)** | Наиболее распространённая иллюстративная традиция (рисунки 1910 г.); основа многих обучающих материалов.           | Иллюстрации в `assets/cards/` и комментарии в скрипте загрузки отсылают к RWS на Wikimedia Commons.                                                                                                                                        |
| **Прямое положение (upright)**                    | Карта «стоит» нормально относительно гадающего; обычно связывают с более открытым или прямым значением.            | **Прямая**; `reversed === false`. В подписи к фото — только имя карты; в толковании про прямое положение **не** пишем отдельно — это состояние по умолчанию. Для «на день» первая строка разбора — метка «О чём здесь речь», не имя карты. |
| **Перевёрнутое положение (reversed)**             | Карта перевёрнута на 180°; в интерпретации часто — задержка, внутренняя сторона, «тень» смысла (школы расходятся). | **Перевёрнутая**; `reversed === true`; картинка в боте совпадает с этим; в подписи и в промпте помечается явно (`… (перевёрнутая)` или суффикс в списке позиций).                                                                          |
| **Расклад (spread)**                              | Схема: сколько карт, в каком порядке и что означает каждая позиция.                                                | «На день», «прошлое — настоящее — будущее», **глубинная диагностика** (сессия до 7 триплетов).                                                                                                                                             |
| **Позиция расклада**                              | Место карты в схеме (например «прошлое») и смысл, который ему приписывают.                                         | «Прошлое», «Настоящее», «Будущее» в тексте и на композите.                                                                                                                                                                                 |
| **Толкование / интерпретация**                    | Связывание выпавшей карты (и позиции) с вопросом или контекстом.                                                   | **Разбор** — текст от модели по промптам.                                                                                                                                                                                                  |
| **Чтение (reading)**                              | Сеанс: вопрос (явный или нет), расклад и толкование.                                                               | Один запрос пользователя = одно чтение в упрощённом виде.                                                                                                                                                                                  |
| **Карта дня**                                     | Распространённая практика: одна карта как фон дня или фокус внимания.                                              | Близко к сценарию **На день**; подпись к фото — **Карта на день:** и строка карты (`dayCardFaceCaptionHtml`).                                                                                                                              |
| **Архетип**                                       | Устойчивый образ или роль (часто в разговоре о старших арканах и придворных).                                      | В промптах — ориентация и «тень» архетипа при перевёрнутой карте.                                                                                                                                                                          |
| **Шут (The Fool)**                                | Нулевой старший аркан; старт «пути», непредсказуемость, начало цикла.                                              | Карта `id` 0, имя «Шут».                                                                                                                                                                                                                   |

## 3. Ориентация и как карта показывается пользователю

| Статья                   | Что это                                                                                                                                                                                                                                    | Где в коде                                                                              |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| **Вытянутая карта**      | Карта уже с известной ориентацией — то, что можно подписать, передать в промпт и (если есть файл) отправить картинкой.                                                                                                                     | тип `DrawnCard`                                                                         |
| **Ориентация**           | Прямая или перевёрнутая относительно гадающего. В коде хранится в поле `reversed` (да/нет).                                                                                                                                                | `DrawnCard.reversed`; `orientationLabel` (для внутренних подписей и перевёрнутой ветки) |
| **Прямая (карта)**       | `reversed` выключен. Модель получает «обычное положение» и инструкцию **не** писать пользователю про ориентацию (ни «прямая», ни «в прямом положении»).                                                                                    | `prompts.ts` (`ORIENTATION_HINT`, контекст карты дня)                                   |
| **Перевёрнутая (карта)** | `reversed` включён. Для Telegram картинку переворачивают на 180° от исходного JPEG; в тексте для человека положение указывается явно.                                                                                                      | `cardPhotoInput.ts`; `spreadComposite.ts`; `formatDrawnLine`                            |
| **Строка карты**         | Короткая строка для подписи к фото и контекста в промпте: **только имя** карты, если прямая; если перевёрнутая — `Имя (перевёрнутая)`. Прямое положение в скобках не дублируем; в тексте «на день» имя не дублируется — оно уже в подписи. | `formatDrawnLine`                                                                       |

## 5. Разбор, бренд-формат и запросы к модели

| Статья                           | Что это                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Где в коде                                                                   |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **Бренд-гайд**                   | Документ: голос Водоворота в чате, голос толкования, метки блоков ответа ИИ, вёрстка в Telegram.                                                                                                                                                                                                                                                                                                                                                                            | `docs/BRAND-GUIDE.md`                                                        |
| **Формат ответа толкования**     | Фиксированные строки-метки (без тире в конце) и пустые строки между блоками. Список меток: `READING_SECTION_LABELS` в `brandFormat.ts`. «На день»: карта уже в подписи к фото — первая строка разбора = метка **О чём здесь речь** → **Коротко о дне** → короткий финал без метки. Тройной расклад: позиции в подписи к коллажу — в тексте **Прошлое**, **Настоящее**, **Будущее**, **Как это сходится**; в абзацах о положении карты говорят только если она перевёрнутая. | `brandFormat.ts`; промпты в `prompts.ts`                                     |
| **Разбор**                       | Текст толкования по картам; формируется моделью по инструкциям и бренд-формату.                                                                                                                                                                                                                                                                                                                                                                                             | `completeChat`; `ai.ts`; `prompts.ts`                                        |
| **Системный промпт**             | Постоянная инструкция модели: соблюдать формат меток; только русский; читаемые в мессенджере фразы; спокойный взрослый тон; без техники и без «я ИИ».                                                                                                                                                                                                                                                                                                                       | `SYSTEM_PROMPT`; `ai.ts`                                                     |
| **Подсказка по ориентации**      | Как учитывать смысл обычной и перевёрнутой карты **внутри** толкования и что **не** говорить пользователю про обычное положение (оно по умолчанию).                                                                                                                                                                                                                                                                                                                         | `ORIENTATION_HINT`; `readingPromptRules.ts`                                  |
| **Промпт карты дня**             | Запрос под одну карту + архетип толкователя + контекст ориентации + safety + точный каркас `brandFormatDayPromptBlock`.                                                                                                                                                                                                                                                                                                                                                     | `cardOfDayPrompt`; `prompts.ts`                                              |
| **Промпт трёх позиций**          | Запрос под три позиции + архетип толкователя + вопрос + список позиций + safety + `brandFormatSpreadPromptBlock`.                                                                                                                                                                                                                                                                                                                                                           | `pastPresentFuturePrompt`; `prompts.ts`                                      |
| **Ответ модели**                 | Успешный ответ API: из поля результата извлекают строку разбора и отправляют пользователю (при необходимости нарезав на части). _См._ нарезка разбора.                                                                                                                                                                                                                                                                                                                      | `completeChat`; `ai.ts`; `bot.ts`                                            |
| **Нарезка разбора**              | Если текст длиннее лимита одного сообщения Telegram, его делят на несколько `reply` с разбивкой по абзацам и пробелам.                                                                                                                                                                                                                                                                                                                                                      | `splitForTelegram`; `bot.ts`                                                 |
| **Оформление толкования (HTML)** | Перед нарезкой — удаление служебных строк («Пустая строка.» и варианты, `stripModelFormatArtifacts`). После нарезки экранирование `& < >`; строки, совпадающие с `READING_SECTION_LABELS` (после trim), оборачиваются в `<b>`; `parse_mode: HTML`. Подписи к фото с картами собираются отдельными шаблонами с жирным названием расклада.                                                                                                                                    | `readingTelegramHtml.ts`; `brandFormat.ts`; `bot.ts`; `cardOfDayDelivery.ts` |
