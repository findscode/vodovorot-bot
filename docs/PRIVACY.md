# Политика конфиденциальности — Водоворот (Vodovorot)

**Дата:** 9 апреля 2026 г.  
**Контакт оператора:** указать e-mail или Telegram @username.

## Назначение

Бот **Водоворот** в Telegram. Режим работы: **только личные сообщения** (private), группы и каналы не обслуживаются.

## Данные

1. **Telegram user id** и поля профиля, которые Telegram передаёт боту при обновлениях — для ответов в чате и для опционального ограничения доступа (whitelist на стороне оператора).
2. **Действия в чате** (команды, нажатия inline-кнопок, служебные поля апдейтов), необходимые для выдачи расклада и текста толкования.
3. **Логи на сервере** оператора — по его настройкам; в открытый доступ не публикуются как продукт бота.
4. **Файл лимита «карта на день»** (если включён): в JSON хранится сопоставление user id и календарной даты последнего успешного толкования (граница суток — часовой пояс оператора, по умолчанию Москва); путь — `DAY_DRAW_STATE_PATH`, опционально `DAY_DRAW_TIMEZONE`.
5. **Команда /last:** в оперативной памяти процесса может храниться последнее выданное пользователю толкование (без отдельной БД; после перезапуска процесса не сохраняется).

## ИИ

Текст толкования запрашивается у **Cloudflare Workers AI**. На сторону Cloudflare уходит **промпт** (описание карт и инструкции формата ответа). Имя и @username пользователя в промпт **не включаются** по умолчанию.

## Третьи стороны

- **Telegram** — обработка сообщений по [политике Telegram](https://telegram.org/privacy).
- **Cloudflare** — обработка запросов к ИИ по [политике Cloudflare](https://www.cloudflare.com/privacypolicy/).

Иной состав обработчиков возможен при иной конфигурации деплоя; фактический список — у оператора.

## Хранение

Переписка в виде отдельной долговременной БД в типовой сборке проекта **не предусмотрена**. Файл лимита «на день», кратковременный кеш для `/last` и логи контролирует оператор (сроки, удаление, сброс при переустановке сервера).

## Пользователь

Можно прекратить использование и заблокировать бота в Telegram. Запросы на удаление данных — контакту оператора (если применимо по закону).

## Изменения

Текст может обновляться; версия в репозитории по URL из настроек BotFather.

Публичный запуск: проверка текста на соответствие закону вашей юрисдикции — задача оператора.
