# Политика конфиденциальности — Водоворот (Vodovorot)

**Дата:** 9 апреля 2026 г.  
**Контакт оператора бота:** укажите здесь актуальный e-mail или @username в Telegram после публикации (владелец репозитория / сервиса).

Этот документ описывает, как обрабатываются данные при использовании Telegram-бота **Водоворот**. Бот рассчитан на **личные сообщения** с пользователем, не на группы.

## Какие данные обрабатываются

- **Идентификатор пользователя Telegram (user id)** и данные профиля, которые Telegram передаёт боту в обычном режиме работы (например, имя в чате), — чтобы отвечать вам в личке и при необходимости применять ограничения доступа (whitelist), настроенные оператором.
- **Содержимое взаимодействий с ботом** (команды, нажатия кнопок, служебные обновления), необходимое для выдачи расклада и толкования.
- **Технические логи** на стороне сервера (без публикации в открытый доступ), в том числе для диагностики ошибок.

Для лимита «карта на день» на сервере может храниться **сопоставление вашего user id с датой последнего гадания** (файл состояния; путь задаётся оператором). Это не публичный профиль и не лента сообщений.

## Как используются данные

- Чтобы **предоставить функции бота**: показ карт, запрос и выдача текстового толкования, соблюдение лимитов и правил доступа.
- Толкование формируется с помощью **сервиса искусственного интеллекта** (у оператора бота — **Cloudflare Workers AI**): в провайдера уходит **текст запроса (промпт)** с описанием выпавших карт и правилами ответа, **без передачи вашего имени или @username** в качестве обязательной части промпта. Идентификатор пользователя в промпт по умолчанию **не подставляется**.

## Передача третьим лицам

- **Telegram** — согласно [политике Telegram](https://telegram.org/privacy) и настройкам, которые вы применяете в мессенджере.
- **Cloudflare** — при каждом запросе толкования: обработка запроса к модели ИИ на стороне Cloudflare в соответствии с [условиями Cloudflare](https://www.cloudflare.com/privacypolicy/).
- Иные третьи лица **не продаются** ваши диалоги как товар; состав провайдеров должен соответствовать фактической конфигурации деплоя (см. документацию оператора).

## Хранение и сроки

- Сообщения **не предназначены** для долгого хранения как переписка в отдельной базе «чатов» в рамках типового деплоя этого проекта; оператор может настраивать логирование на своей инфраструктуре.
- Файл лимита «карта дня» хранит только **идентификаторы и даты** в служебном JSON; срок хранения определяется политикой оператора (файл можно удалить или сбросить при переустановке сервера).

## Ваши действия

- Вы можете **прекратить использование** бота и заблокировать его в Telegram.
- Запросы на **удаление или выгрузку** данных, если они применимы к вашей юрисдикции, направляйте **контакту оператора**, указанному в начале документа.

## Изменения

Оператор может обновлять эту политику; актуальная версия — в репозитории проекта по ссылке, указанной в настройках бота в BotFather.
