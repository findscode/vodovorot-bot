# UX polish 3.2.0 — план для агента

**Цель:** улучшить опыт пользователя в Telegram **без смены архитектуры**. Напильник, не топор.

**Версия релиза:** `3.2.0` (один PR, один блок в `CHANGELOG.md`).

**База:** `3.1.1` — глубинная диагностика, PNG `assets/cards/*.png`, подпись к фото с нумерацией вопросов (`1. «…»`, пустая строка между вопросами).

---

## Ограничения (не нарушать)

- In-memory сессии deep, TTL 24 ч — **без SQLite**.
- Не добавлять команду `/deep` (только кнопка `deep`).
- Не менять порядок «На день»: ИИ → фото → текст.
- Не переводить толкования на MarkdownV2 (остаётся HTML).
- Не менять промпты OpenRouter и логику коллажа (кроме **одной** опциональной текстовой подсказки UX-3.2).
- Не нумеровать шаги в **подписи к фото** («3 из 7») — только в **сообщениях бота**.
- Обращение на **«ты»** везде в `botCopy.ts`.

---

## Вне scope

| Не делать                                         | Причина               |
| ------------------------------------------------- | --------------------- |
| SQLite / восстановление сессии после рестарта     | Отдельный эпик        |
| Wizard, новые экраны, эмодзи вместо текста кнопок | Ломает текущий UX     |
| ИИ→фото для spread                                | Меняет привычный flow |
| Рефакторинг `bot.ts` / перенос всех текстов в БД  | Не цель               |

## Фаза 1 — Глубинная диагностика (обратная связь)

### UX-1.1 · Команды во время сессии — ответ вместо тишины

|              |                                                                                                                                                                                                                  |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Файлы**    | `src/botCopy.ts`, `src/handlers/middleware.ts`                                                                                                                                                                   |
| **Импорт**   | `DEEP_MAX_TRIPLETS` из `src/deepReading/constants.ts`                                                                                                                                                            |
| **Сейчас**   | `registerDeepSessionMiddleware`: при `text` с `/` → `return` без ответа.                                                                                                                                         |
| **Сделать**  | Функция `deepSessionBlockedMessageHtml(tripletsDone: number): string` — сколько вопросов уже сделано, сколько осталось до 7, напоминание про «Закончить гадание», что `/menu` и `/help` заработают после финала. |
| **Сделать**  | Если активная deep-сессия и `text.startsWith('/')`: `ctx.reply(..., { ...keyboardDeepInChain(), ...TELEGRAM_HTML_PARSE })`. Для `isPublicEntryCommand` — тот же текст (не различать).                            |
| **Проверка** | В deep `/menu` и `/help` дают сообщение + кнопка «Закончить гадание».                                                                                                                                            |

### UX-1.2 · Повторный callback `deep`

|              |                                                                                  |
| ------------ | -------------------------------------------------------------------------------- |
| **Файлы**    | `src/botCopy.ts`, `src/handlers/registerDeepReadingHandlers.ts`                  |
| **Сейчас**   | `if (hasActiveDeepSession(uid)) return;` — тишина.                               |
| **Сделать**  | Константа `DEEP_ALREADY_ACTIVE_MESSAGE` + `ctx.reply` с `keyboardDeepInChain()`. |
| **Проверка** | Второй тап «Глубинная диагностика» — текст в чате.                               |

### UX-1.3 · «Осталось N вопросов» после триплета

|              |                                                                                                                                                                                                                                                                                           |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Файлы**    | `src/botCopy.ts`, `src/deepReading/deepReadingDelivery.ts`                                                                                                                                                                                                                                |
| **Сейчас**   | `DEEP_CONTINUE_HINT` без чисел.                                                                                                                                                                                                                                                           |
| **Сделать**  | `deepContinueHintHtml(tripletsDone: number)` — после шага `tripletsDone` = `session.triplets.length`, осталось `DEEP_MAX_TRIPLETS - tripletsDone`. Подставить в `sendPlainReadingChunksToChat` / последний чанк или отдельный `reply` после толкования (как сейчас `DEEP_CONTINUE_HINT`). |
| **Проверка** | После 3-го вопроса в чате «осталось до 4»; в caption фото по-прежнему только `1. «вопрос»` без «3 из 7».                                                                                                                                                                                  |

|              |                                                                                                                                 |
