## Description

Гадание персональное; группы и каналы не поддерживаются. Не спамить группу ответами.

## Acceptance criteria

- [ ] В `bot.ts` (или отдельном модуле) до основных хендлеров: если `ctx.chat?.type !== 'private'`, не передавать дальше в бизнес-логику (ранний `return`).
- [ ] Не отправлять сообщения в группу/канал (тихий игнор).
- [ ] Лог в debug-уровне опционально: один раз на тип чата или throttled — по желанию, без шума.
- [ ] Краткая строка в `docs/DEPLOY.md` или ссылка в ROADMAP: бот только для ЛС.

## Notes

Telegraf: `ctx.chat.type` — `private` | `group` | `supergroup` | `channel`. Порядок middleware: после `dotenv`, до whitelist.
