## Description

Заменить UTC-границу суток на московскую дату для ключа лимита «карты дня».

## Acceptance criteria

- [ ] Функция вида `moscowCalendarDate(now?: Date): string` → `YYYY-MM-DD` в TZ `Europe/Moscow`
- [ ] Использовать в `tryConsumeDayDrawSlot` вместо `utcCalendarDate` (или переименовать/обёртка)
- [ ] Тесты: фиксированные `Date` + ожидаемая московская дата (в т.ч. около полуночи по Москве)
- [ ] Опционально env `DAY_DRAW_TIMEZONE` со значением по умолчанию `Europe/Moscow`
- [ ] Зависимость: пакет при необходимости (`luxon` / `date-fns-tz`) или `Intl`, если достаточно
