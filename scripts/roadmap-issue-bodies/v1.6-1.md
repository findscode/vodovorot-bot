## Description

Один набор правил для всех пользователей: ясно новичку, не раздражает опытного. Без env `READING_DEPTH` и без режимов «новичок/эксперт».

## Acceptance criteria

- [ ] Один набор правил для всех: простой русский, без морализаторства, без энциклопедичности
- [ ] Нейтральное напоминание про перевёрнутую карту (при необходимости усилить)
- [ ] Одна короткая «рамка» в конце или в фиксированном блоке: размышление ≠ приговор (не дублировать в каждом абзаце)
- [ ] Сохранить метки `brandFormat` и запреты (медицина, юриспруденция, финансы и т.д.)
- [ ] Ручная или полуавтоматическая проверка 3–5 ответов на типичные карты
