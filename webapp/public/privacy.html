Политика конфиденциальности

Водоворот (Vodovorot)

Дата: 25 мая 2026 г.

Контакт оператора: https://t.me/pjbaraboolkin

Назначение

Бот Водоворот в Telegram. Режим работы: только личные сообщения (private), группы и каналы не обслуживаются.

Данные

  1. Telegram user id и поля профиля, которые Telegram передаёт боту при обновлениях — для ответов в чате и для учёта уровня доступа (базовый уровень, Premium, админы — в локальной БД оператора).
  2. Действия в чате (команды, нажатия inline-кнопок, служебные поля апдейтов), необходимые для выдачи расклада и текста толкования.
  3. Логи на сервере оператора — по его настройкам; в открытый доступ не публикуются как продукт бота.
  4. Локальная база SQLite на сервере оператора (путь задаётся DATABASE_PATH, по умолчанию файл в каталоге data/): слот «карта дня» (day_draw_slots: user id и календарная дата); слоты расклада «три карты» на basic (spread_draw_slots, до 3 за сутки); подписка на ежедневную карту; срок Premium; флаг админа; промокоды; last_seen_release — какой релиз in-bot «Что нового» пользователь уже закрыл. Legacy JSON из 1.x может один раз импортироваться при старте, если задан DAY_DRAW_STATE_PATH или есть файл по умолчанию.
  5. Глубинная диагностика (с v3.0): во время активного гадания вопросы пользователя, служебные краткие резюме шагов и данные для коллажа хранятся только в оперативной памяти процесса бота (до 24 часов без активности, до нажатия «Закончить гадание» или отмены до первого вопроса). В SQLite не записываются. После перезапуска сервиса незавершённая сессия не восстанавливается.
  6. Расклад «три карты» (с v3.7): ожидание вопроса после «Начать» — in-memory (TTL ~15 мин), как у spread-сессии до выдачи карт.

ИИ

Текст толкования запрашивается у OpenRouter (Chat Completions; на сторону провайдера уходит промпт — описание карт и инструкции формата ответа). Имя и @username пользователя в промпт не включаются по умолчанию. Если первая выдача по эвристике выглядит преимущественно не-русской (много латинских букв в тексте), бот может отправить второй запрос: на вход уходит уже сгенерированный текст толкования и инструкция редактора «переписать на русский», без добавления персональных данных.

Третьи стороны

  • Telegram — обработка сообщений по политике Telegram.
  • OpenRouter — маршрутизация запросов к языковым моделям; см. Privacy Policy OpenRouter.

Иной состав обработчиков возможен при иной конфигурации деплоя; фактический список — у оператора.

Хранение

Долговременное хранение в типовой сборке — файл SQLite (см. выше). Сроки хранения, резервное копирование БД, удаление данных по запросу пользователя — зона ответственности оператора.

Пользователь

Можно прекратить использование и заблокировать бота в Telegram. Запросы на удаление данных — контакту оператора (если применимо по закону).

Изменения

Текст может обновляться; актуальная версия — на этой странице Mini App и в docs/PRIVACY.md репозитория оператора.

Публичный запуск: проверка текста на соответствие закону вашей юрисдикции — задача оператора.
